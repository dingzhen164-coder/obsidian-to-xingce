# 卡片设计规范

> 生成卡片前必读。第一节是所有书通用的规则；第二、三节是两类书各自的拆卡策略；第四节是预览格式。

## 一、通用规则（所有书）

1. **一张卡只问一个知识点。** 判断标准：答错时，你能说清“是哪一个点没记住”。答案里出现“以及/同时/另外”往往意味着该拆。
2. **问题必须脱离书本也能看懂。** 写全主语和范围，禁止“本章/上文/该方法/这一讲/如上”。
   - ✗ 该方法的第二步是什么？
   - ✓ 定义判断的“解题三步”中，第二步做什么？
3. **答案要短、可对照。** 理想 ≤ 80 字，硬上限 400 字。长答案说明要拆，或者本来就该是流程/列表卡（用换行分点）。
4. **问法要明确是“在检索什么”。** 用“是什么 / 怎么做 / 什么时候用 / 区别是 / 共几项分别是 / 期限是多少”开头或结尾，不要问“谈谈……”。
5. **改写，不抄原文。** 把原文的陈述改成可检索的问答；但**数字、期限、主体、条件、例外一律照原文，不得“优化”**。
6. **不造书里没有的内容。** 每张卡必须有 `evidence`（书里的一小段原文，8–40 字，复制原文，不要改写）。`build_tsv.py --source` 会核对它是否真在书里。自己的补充、常识、外部知识，不写进卡片。
7. **不凑数。** 重复表述同一点的卡、纯修辞/鼓励/过渡性文字，一律不做卡。
8. **标签**：`第N章` + 主题词（如 `拆词法`）。不含空格；层级用 `::`。
9. **出处（source）**：`第N章 小节名`；有页码/条文号时一并写，如 `第3章 二、…（P52）`。

### 反面样例

| 问题 | 为什么不行 | 怎么改 |
|---|---|---|
| Q：简述本章内容 | 太大、没有检索点 | 删除，拆成具体知识点 |
| Q：解题三步分别是什么？A：（三条各一长段） | 一张卡塞三个知识点，答案过长 | 一张“总览”只答每步一句；每步各自展开一张 |
| Q：政府与企业有何不同？A：政府不营利 | 只答一半 | A：政府不以营利为目的；企业往往以营利为目的 |
| Q：该方法什么时候用？ | 依赖上下文 | 写出方法名和适用对象 |

## 二、方法论型（例：行测讲义）

**特点**：一章里真正的知识点往往只有几句话，篇幅主要是例题。价值在于**形成体系、能在题干里认出该用哪个方法**，而不是背字句。

**取卡优先级（从高到低）**：

1. **体系卡**：总流程、分类总览、方法之间的先后/从属关系。例：“多定义读不出唯一答案时，下一步做什么？”这类卡串起各章，**全书结束后单独做一组**（约 8–15 张，标签 `体系`）。
2. **方法卡（是什么 + 怎么做）**：方法名 → 步骤/做法。
3. **触发卡（什么时候用）**：反向——从**情境/信号**问到方法。例：“题干里出现‘在……中’这类表述，应该先想到哪类关键信息？”这是方法论型最该有、最容易漏的一类。
4. **规则卡**：“当 X 时 → 做 Y”，必要时写原因。
5. **易错卡（反模式）**：书里点明的坑、失败模式。
6. **例题迁移卡**：见下。

**例题的处理（重点）**：
- **不要一题一卡，不要把整道题搬进卡片**（太长、记的是答案不是方法）。
- 只为**最典型或最易错**的例题做卡，**每个方法 1–2 张**；其余例题只作为 `source`/`evidence` 的依据，不单独成卡。
- 例题卡的写法：问“**题干有什么特征 / 该抓哪个信息 / 为什么排除某类选项**”，而不是问这题选什么。
  - ✓ Q：定义题中出现“互惠焦虑”这类定义词，拆词后应落到哪个前提条件上？ A：“接受别人的帮助或恩惠之后”——受益方是自己、给予方是别人。
  - ✗ Q：（2026四川）互惠焦虑……下列没有体现互惠焦虑的是？（整题）
- 真题的年份/正确率可放进 `source`，不放进问题。

**密度参考**：每个可独立复述的方法/规则通常 2–3 张（做法 + 触发 + 易错，视有无而定），每章再加 1–3 张例题迁移卡。**由内容决定，不设固定数**；一章只有三四个知识点就只出十来张，不要用例题把数量撑起来。

## 三、记忆型（例：法考教材）

**特点**：知识点极多、例题很少，重点是**逐点记牢，准确**。宁可卡多，也不要漏掉能考的点；但**每张仍只问一个点**。

**常见卡型**：

| 类型 | 问法 | 注意 |
|---|---|---|
| 定义/概念 | X 是什么？ | 答案保留定义里的关键限定词 |
| 构成要件 / 条件 | X 的构成要件有几个？分别是什么？ | 见下方“列举型” |
| 数字类 | 期限 / 数额 / 比例是多少？ | **逐字照抄**，带条件（“自……起算”）。每个数字一张卡 |
| 区别辨析 | A 与 B 的区别是什么？ | 一个区别点一张卡，不要一张卡列五条区别 |
| 例外 / 但书 | X 的例外情形有哪些？ | 单独成卡，常考 |
| 后果 / 效力 | X 的法律后果是什么？ | 主体、后果分清 |
| 出处 | 哪条规定了 X？ | 仅在书中明确给出条文号时才做 |
| 案例判断 | （简化案情）该行为是否构成 X？ | 只为书中确有的少数例题做卡，案情压到最少 |

**列举型的拆法**：
- ≤ 4 项：一张卡，问中写明“共几项”，答案按序号。
- 5–8 项：一张**总览卡**（只答数量和各项名称）＋ 对易混/重点项各做一张**展开卡**。
- > 8 项：按类别拆成若干组，每组一张，再加一张总览。

**精确性红线**：数字、期限、“应当/可以/不得”、主体、前置条件、例外——**不得改写、不得合并、不得补全**。拿不准就保留原文措辞，并在预览中标出让用户确认。

**密度参考**：一个段落通常 1–3 个知识点；一页教材 5–15 张卡是常见范围。仍以“该点是否可单独考到”为准。

## 四、预览格式（Step 4 必须先给用户看）

对**每一章**给出：

```
### 第N章 章名（约 X 字）
- 知识点/方法数：约 N 个（简列 3–6 个名称）
- 预计卡数：约 N 张（方法卡 a / 触发卡 b / 规则卡 c / 易错卡 d / 例题迁移卡 e ……）
- 样卡（3–5 张，覆盖不同类型）：
  1. Q：… / A：… （出处，类型）
```

最后汇总：全书预计总卡数、两类书的拆卡策略确认、需要用户决定的点（例如“是否把例题迁移卡限制在每方法 1 张”“数字类是否全做”），然后**停下，等用户确认或修改**，再开始全书生成。

估算方法：先快速扫该章的小标题与小结，**数出知识点个数**，再乘以对应类型的每点卡数；不要用字数直接换算（例题多的章字数大，但卡不多）。
