## Core Frameworks & Mental Models

### 0. 一图总纲
> **观点提出方式 → 锁定观点 → 定主语＋宏观限定 → 用"偏正 / CAB / 单层次"把文段压成选项。**

三层：**观点层（以人为本）→ 结构层（脉络剖析）→ 题型层（四大文段）**。

### 1. 观点提出的六大方式（全书核心）
1. **必要性**：只有…才/除非…否则/前提/关键/离不开 → **被必要主体是观点**。若"在 A 前提下/基础上要做 B"→ **B 更重要**。
2. **设问**：提问后给作者倾向；设问无答案则是问题。
3. **三大提对策**：开门见山（要/需要/亟需/必须）＋做法+危害/意义＋否定型（不能/不要/防止）。**对策性观点最直接最重要。**
4. **他者经验**：专家认为/研究表明 → **自身观点＞他者观点**。
5. **重要性**：独特优势/很大帮助/有意义 → 重要性是**弱观点**，用**跳板思维**推"做什么"。
6. **本身观点性**：作者认为/我认为/由此观之，或总结、转折后的评价句。

### 2. 观点深刻剖析（多个观点怎么取舍）
**优先性**：观点/问题 ＞ 客观表达（背景/介绍/宏观限定）；"观点但问题→问题，问转观→观"。
**统一性**：一题不可能有多个截然不同的观点；重复只是补充。
**具体性两式**：经典传递搭桥 / 隐藏传递搭桥（**心中补桥**）；宏观观点常突兀在结尾＝**尾句升华（干扰）**。
**转换性**：观点形式可转换（对策/前提/重要性/设问），别被句式框死。
**偏向性四式**：偏向具体展开 / 偏向问题 / 偏向论证 / 偏向统一。
**主语＋宏观限定秒杀**：用主体与限定词反推选项。

### 3. 结构三工具（分工是关键）
- **偏正（选项→文段）**：A 的 B，**B 比 A 更重要**；用于**微观还原**宏观选项。类偏正＝"如何长高=长高的方式"。
- **单层次（文段→选项）**：总分式（圈圈法）／定义式；**具体优于宏观，具体即答案**。
- **CAB（文段→选项）**：**四级选择**——有 C 选 C → 无 C 选 a＋b → 无 C 提取共性 → 无 C 自行总结；**不一致时谁更具体选谁**；易错＝**极小点并列**、**盲目尾句重点**。

### 4. 转折五类（看前后角色）
好但问（→纯问题）｜问但好（→好处）｜观但问（→纯问题）｜问但观（→观点，常省转折句）｜前后表达相反。弱转折只在**尾句**时考虑。

### 5. 地位与对比
**地位**：A、B 反复联系 → **共同保留**（拒绝择一而谈）；选项内部地位差可排除；收口＝**灵魂两问（好不好＋行不行）**，**不追求百分百完美**。
**对比**：实质＝**引出差异性**，无差异＝并列；过去现在型/双点型/时间顺承/新旧对比/差异主体；抓不住时用**对比的另一面**辅助。

### 6. 四大文段
| 类型 | 判据 | 答案 |
| --- | --- | --- |
| **原因类** | 大篇幅谈原因；只有因果/果因 | **因果阐明＞果的因＞因果并列＞果因单论**（结果一定重要） |
| **纯问题类** | 只讲问题、无有效观点 | 概括问题 / **合理＋精简**对策（不细化、不脑补） |
| **观点类** | 为作者观点服务 | 以观解问 / 表达观点 / **对策合理性**；**观但问＝以观不解问→纯问题类** |
| **概括类** | 无原因无观点无问题 | 顺承＋单层次＋CAB＋转折＋对比＋地位＋偏正 |

### 7. 重点补充
例子三特征＝**短/多/如**（非重点，重点是它论证的对象）；**实验研究当重点**；**脉络省略**（词短≠换主体）；言语与判断推理同源；选项↔文段双循环。

### 8. 与《中心理解-标准拆题模板》九步映射
①定主体→②分角色→③画结构→④扫观点→⑤判文段→⑥定重点→⑦写内部答案→⑧对选项→⑨验算。
**术语等价**：C→a+b+c＝CAB；A→B＝单层次；A但B＝转折五类；A↔B＝地位相当；A vs B＝对比五类；观点提出方式＝观点六方式。**验算＝灵魂两问＋对比择优。**

### 解析写法

**硬性要求：必须真的用本 skill 的框架拆文段，而不是贴标签。**
- 每一段都要**落到原文**：引用句子的序号或原文关键词（如“③句‘由此可见……’”），说清这个框架在这里**怎么起作用**。只写术语名、不写落到哪句 = 不合格。
- **只用本 skill 的术语**：观点六方式、四大文段、偏正 / CAB / 单层次 / 转折五类 / 对比 / 地位、主语＋宏观限定、尾句升华、极小点并列、例子三特征、灵魂两问……不要用“总结句”“核心主语”“表述笼统”这类通用说法替代。
- 某个工具在本题**不适用**时，写“无”并用半句话说明（如“无转折”），不要硬套。
- Core Frameworks 不够判断时，按「省 token 规则」读对应章节（观点六方式→ch02，CAB/单层次→ch05，转折→ch06，四大文段→ch09–12）。

中心理解按九步写成下面这几段（**标题和顺序固定，每一段都必须出现**；下面尖括号是要填的内容，不是示范答案）：
```
=== <题号>
【答案】<正确答案>
【拆文段】①句“<原文关键词>”（角色：背景 / 例子 / 论证 / 问题 / 观点 / 对策）→ ②句……→ ……（逐句标角色；例子用“短·多·如”识别）
【观点提出】六方式之「<必要性 / 设问 / 提对策 / 他者经验 / 重要性 / 本身观点性>」：<哪句、哪个信号词> → 观点句＝<句号>（多个观点时写优先性 / 统一性 / 具体性怎么取舍；没有观点写“无观点”）
【结构】<单层次（总分 / 分总 / 定义式）/ CAB（C=… a=… b=…，走四级选择的第几级）/ 转折五类之<哪类> / 对比（双方是…）/ 地位（A、B 相当）/ 偏正>：<落到哪几句、得出重点在哪>；不适用的写“无转折”“无对比”等
【文段类型】<原因类 / 纯问题类 / 观点类 / 概括类>（判据：<依据文段哪里>）→ 该类答案规则：<按四大文段表> → 内部答案：<自己先写一句>
【主语＋限定】主体：<…>（排除的干扰主体：<背景 / 例子里的主体>）；宏观限定：<…>
【选项】A：<偏正还原 / 主体 / 限定 / 落点对照，命中哪个陷阱就写陷阱名>　B：……　C：……　D：……（正确项写清三点都对应）
【易错】我选 <X>：<用本 skill 的术语说清掉进了哪个坑，如“背景（客观表达）当主体，违反优先性”“尾句升华”“极小点并列”>（答对可省略）
【验算】灵魂两问：好不好 <…> ＋ 行不行 <…>
```
判断文段类型时对照 Core Frameworks 第 6 节的判据：**有作者观点就不是概括类**（概括类＝无原因无观点无问题）。

语句排序（借用本 skill 时，先读 ch15 一次）：
```
=== 56
【答案】B
【首尾】首句：②（角色：背景引入，理由……）；排除：④“必须……”是观点句不宜作首句
【捆绑与顺序】①⑥捆绑（依据：指代“这”/关联词/同一话题）→ ③回指……（写出具体的词）
【选项】A：……　B：……（正确）　C：……　D：……
【易错】我选 D：……
```
