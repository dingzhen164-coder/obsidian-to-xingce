# 第一章：定义判断入门——考情 · 解题三步 · 拆词法 · 主客体

## Core Idea
定义判断是"给出定义，在四个选项中做符合性判断"；不必逐字读，只读重点——先看提问，再看定义所在句，抓两类关键信息：**定义词（拆词法）**与**主客体**。

## Frameworks Introduced
- **解题三步**：①看提问（选是/选非 + 定义词叫什么）→ ②看题干（优先读"定义所在的那一句"，后续解释可略读）→ ③看选项（简单题直接选对的；难题排错、对比择优）。
  - Why：问法看错全盘皆错；定义句读懂后，后面的解释说明常可不读，省时间。
  - 失败模式：从头顺着读全文、没看清"不属于"。
- **拆词法**：定义词是命题人起的名字，命名本身就揭示核心 → 拆开后分头回题干找对应表述。
  - 例：换乘消费＝至少两个地点/城市＋必须花钱；同病异治＝同病＋异治；绿色＝节约资源、保护环境；虚拟＝无实际形态/依托网络；替代＝至少两个对象；被害人＝先有加害人；平台＝可供多方参与；自＝不引入外部力量；探店＝必须有"店"。
  - 定义词通俗易懂 → 拆词后可直接看选项；有疑虑 → 重点核对题干中与定义词相关的表述。
- **主客体**："我教你"——教的人是主体（主语），被教的人是客体（宾语）。主客体不符，其余不必再看。
  - 修饰/限定越多（"的"字提示），范围越窄，越容易成考点。
- **四大痛点→破题方向**：字多读得慢→挑重点读；太难读不懂→挑能读懂的读；重点抓不住→挑本质读；二择大失败→对比差异、对比择优。

## Key Concepts
- **政府 vs 企业**：政府不以营利为目的，企业往往以营利为目的（第一条铁律）。
- **公共资源/公共事务的管理者**→主体往往是政府；选项里的"某地/某市/某省"采取行为→可认定为政府（但"管理者"不一律是政府）。
- **个人**：与商家、企业、集体、组织相区分，指单个的人，不是个体工商户。
- **政府类主体范围**：行政机关（各级政府、公安、海关等）、权力机关（人大）、立法机关（全国人大及常委会）、司法机关（法院、检察院）、事业单位（科研所、学校、广播新闻出版、医院等）。
- **种类与数量词**：双方、另一个、两个及以上、多元；自己/他人、自身的、主观的；这个、该、新的、相同/不同。
- **菌类特例**：严格说菌类既非动物也非植物，但命题人常出错——别纠结，看定义词落点（如"设施农业"落点在"设施"，"采集经济"落点在"采集"）。

## Anti-patterns
- **逐字通读、从头顺读**：浪费时间，定义题只需重点。
- **看错问法**：选是/选非搞反。
- **在命题人自己含糊处较真**（菌类、过于宽泛的"农业"）。

## Worked Example
(2025山东)绿色计算：拆"绿色"＝对环境有害影响小/节约资源 → 选项D"设备全部用太阳能发电取代传统电能，降低能耗"对应；A（无线覆盖）与环境无关；B（楼建在校外）方向反了；C（笔记本替代台式）题干无依据。 → D。
(2022湖北选调)质量成本：主体限定为企业 → A项"行政服务中心"是事业单位，主体不符，十秒选A（选非）。

## Key Takeaways
1. 近三年国考55题：简单题≈56%、中等≈42%、难题仅1道；目标"10分钟正确率80%"。
2. 先看提问（选是/选非），再读定义句。
3. 简单题拆词省时间，难题拆词把握本质、二选一时作取舍。
4. 主客体不符直接排除；主客体前有限定词时重点看。
5. 方法是辅助不是圣经——用着不顺手可舍弃。
