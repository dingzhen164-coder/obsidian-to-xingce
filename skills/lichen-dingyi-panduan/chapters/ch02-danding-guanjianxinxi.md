# 第二章：单定义关键信息——前提条件 · 方式目的 · 原因结果 · 解释说明

## Core Idea
读定义句时，除拆词与主客体外，还要盯住四类关键信息：**前提条件、方式目的、原因结果、解释说明**，并积累一批"必看词"（数字、歧视、直接/间接、否定词、数量……）；同时要知道什么**不用看**。

## Frameworks Introduced
- **前提条件**（考得很多，最实用）：常见表述"在……前 / 在……中（时） / 在……后"。选项行为若不落在这个时间区间，直接排除。
  - How：把前提圈出来 → 逐项问"这个行为发生时，是否处在这个区间/场景里？"
  - 例：公共责任"在工作中"→上班途中救人、吃饭聊天都不满足；环境福利绩效"在实现经济目标过程中"→政府划拨经费搞生态建设不满足。
- **方式目的、原因结果**：引导词——方式"通过/利用"，目的"以/以达到"，原因"因为/由于"，结果"导致/使得"。权重：方式目的考得非常多，原因结果相对少。
- **解释说明**（备用通道）：仅在①定义句看不懂，或②看完仍选不出唯一答案时，才往后读；引导词"即……/核心……/也就是说……"后面重点看。
- **关键信息取舍**：不优先看——概念宽泛（农业）、表述抽象（意境/韵味）、冷门生僻（报告文学）；**反复出现的词**一定是关键（重复＝命题人在提示重点）。
- **积累清单**：

| 关键信息 | 常见表述 | 考查方式 |
|---|---|---|
| 变化 | 升级、降级、转型、趋于 | 选项需有前后两个状态 |
| 互动 | 互动、交流、回应、协商 | 要双方有来有往，单向发布不符 |
| 数字 | 数字、算法、大数据、互联网 | 要用上信息处理手段，机械化不算 |
| 歧视 | 歧视、差别对待、有差别 | 对不同对象采取不同措施 |
| 直接 | 直接/间接、含蓄、委婉 | 追问有没有多出一个中间环节 |
| 否定词 | 不、非、未 | 违反否定表述的选项直接排除 |
| 数量 | 若干、各个、几个、两种以上 | 对象数量达标，一个不算 |

## Key Concepts
- **选非题的方向差**：凡与前提条件方向相反的选项几乎可直接锁定（互惠焦虑：是"接受"帮助而非"给予"）。
- **暗示 vs 明示**：含蓄、间接＝迂回；直接吼、写在背上＝明示（暗示效应例）。
- **自己/他人**：受益方须是自己、给予方须是别人（主客体的延伸）。
- **两次以上**：逆境胁迫记忆要求"前期干预"与"再次发生"至少两次，且干预须"非生物"（否定词"非"→老鼠啃食、病原菌侵染都排除）。

## Anti-patterns
- 把解释说明当必读：每道题都往后读，拖慢速度。
- 圈满篇"重点"：不分轻重，到选项时抓不住。
- 在抽象词（审美、意境）上花时间。

## Worked Example
(2022四川)暗示效应：落点——无对抗＋含蓄/抽象/间接＋对方按暗示者期望行动。A（地名早就有，没人暗示）排；B（张飞大吼）太直接排；D（刺字"精忠报国"）是明示排；C（貂蝉哭诉让吕布杀董卓，未直说）符合 → C。

## Key Takeaways
1. 前提条件先问"时间/场景区间"，不落区间的选项直接排。
2. 方式目的 > 原因结果，优先盯前者的引导词。
3. 定义句读得懂就别读解释；读不动或选不出再读。
4. 反复出现的词＝关键；宽泛/抽象/冷门＝一眼扫过。
5. 积累清单靠平时练习补充，不靠背。
