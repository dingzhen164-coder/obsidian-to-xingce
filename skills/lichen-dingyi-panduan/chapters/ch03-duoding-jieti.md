# 第三章：多定义解题——问谁看谁 · 对比差异 · 总分类与子定义

## Core Idea
多定义不是新题型，只是把单定义方法放进更长的题干：**问哪个定义就先看哪个；读不出唯一答案才去读另一个，且只抓两者的差异；总分类（母子）定义中子定义必须先满足母定义。**

## Frameworks Introduced
- **问谁看谁**：先用设问锁定被问的定义，题干中无关部分整段划掉，再继续压缩到可操作的动词。
  - 长题干（如174字、正确率22%的"内部监察法"）先砍一半，只留设问指向的那半。
- **对比差异**：被问定义读完仍选不出 → 横过去读另一个定义；两定义**相同/相近**的表述无效，**不同**的那一点才是破题点。
  - 两条对比路径：对比选项（余下两项差异）、对比题干（另一定义说什么），哪条近走哪条。
- **关键信息复用**：主客体的数量、否定词与组合型选项、"非正式/未出版"、方式与目的分别落在哪一步、拆字定范围。成对定义往往就靠一个否定字区分（非/未/无/不）。
- **"选非"与"只体现"**：设问含"只"→不是证明它符合，而是先把体现了另一种的选项全部排掉，剩下即答案。
- **总分类（母子）定义**：先读母定义，子定义必须满足母定义全部要求；两个子定义间摇摆时回头看母定义。

## Key Concepts
- **母子定义例**：总量指标动态数列（母）→ 时期数列/时点数列（子）：选项"月均工资"是平均数，连母定义（总量指标）都不满足；主动/被动社会收缩都须先有"人口持续流失"；认知决策/直觉决策都须是"竞技运动情景中的运动决策"（主体须是运动员，足球教练从母定义就不成立）。
- **法律事件 vs 法律行为**（例12）：法律事件＝不以当事人意志为转移；差异点＝"是否以意志为转移"。
- **多定义与单定义唯一区别**：命题人设问时往往只问其中一个。

## Anti-patterns
- 从头顺着读 170 字题干。
- 在两个定义相同的表述上反复比较。
- 在子定义之间纠结却不回头看母定义。
- 对"只体现"题去逐项证明而不是先排除另一类。

## Worked Example
(2022国考)时点数列：先读它那一句——①表示某一时点上的数量；②各指标值不能相加；③数值大小与时点间隔长短无关。再回头看母定义"总量指标"：C项"月均工资"是平均数，被排；A税收（时期）、D产量（时期）均可相加，被排；B"员工人数"是时点数 → B。

## Key Takeaways
1. 问哪个，先看哪个——被问定义读得懂就能省下大量时间。
2. 选不出唯一答案才读另一个定义，只抓差异。
3. 否定词在多定义里格外多：非、未、无、不。
4. 母子定义：子必先满足母。
5. 复盘不停留在答案：问"我为什么没找到被问的定义？为什么没想起读另一个？下次先做哪一步？"
