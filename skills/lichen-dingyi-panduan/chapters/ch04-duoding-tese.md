# 第四章：多定义与特色定义——特殊多定义 · 科技类定义 · 常识积累与同构排除

## Core Idea
设问变成"下列说法正确/错误的是"时，读法随之改变：**通读题干＋按选项定位精读**；科技类定义的根本办法是**积累常识**，其次拆词，最后才是慎用的**同构选项排除**。

## Frameworks Introduced
- **特殊多定义读法**：思路与单定义、常规多定义基本一致，但要通读题干（知道有哪些定义、各在哪），再由**选项在讲哪个定义**决定精读哪段。
  - 题干短、定义少 → 重点看定义间差异。
  - 题干长、定义多 → 观其大要，选项需要时再回头找。
- **多线索交叉**：选项涉及多层概念时，先找**一定能判断**的线索，把选项排到只剩两个，再挑最能一击定音的线索核对（统计数据例：先分定性/定量排掉两项，再用"②是否有序"判分类 vs 顺序）。
- **一题三解**（例7，汛期）：①常规对比差异；②拆词直接理解；③同构排除。判断题式设问考的多是**包含与先后关系**——给每个概念标注季节/时段。
- **科技类定义三条办法**：①从真题里积累常识（命题人出过的＝应知应会）；②拆词（定义词带"物理/化学"→调初高中知识）；③同构选项排除（慎用）。
- **物理 vs 化学判据**：有没有新物质生成。有→化学变化；仅物态变化→物理变化。
- **同构选项排除**：几个选项属同一类（如都是"自己要干"），要选"不属于/不同"时答案在孤立的那一个；只提高命中率，不保证正确，复盘仍回到定义本身。

## Key Concepts
- **机会成本 / 显成本 / 隐成本**：显成本＝购买/租用他人要素的总支出；隐成本＝自有且用于生产的要素总价格（自家楼房、管理者应得酬劳是隐成本；付给他人的年薪、年终奖是显成本）。
- **春汛⊃凌汛、夏汛⊃伏汛**；春汛又叫桃汛；伏汛在夏季，凌汛在春季，故"伏汛在凌汛前"错。
- **分类数据 vs 顺序数据**：区别在"某一类别"与"某一有序类别"；婚姻状况（未婚/已婚/离异/丧偶）无序→分类数据。
- **自变量/因变量/控制变量**：自变量由实验者操作；因变量随自变量变；控制变量是除自变量外的其他影响因素。
- **物理分支**：声学、光学（直线传播、折射、反射、散射）、电磁学、热学（物态变化六种）、力学；**化学**：元素、单质/化合物/混合物、燃烧/生锈/发酵/腐败/酸碱中和/催化。

## Anti-patterns
- 把"选项不一定都符合定义"当成矛盾：只需找出设问要求的那一个。
- 对所有线索平均用力。
- 把同构排除当主力方法。
- 做完题不补常识。

## Worked Example
(2021国考)统计数据四组数据题：③④是具体数字观测值→定量；①②是文字类别→定性。A项把④说成分类→排；B项把②说成定量→排。剩C、D，只看②：未婚/已婚/离异/丧偶无先后次序→分类数据，C错 → D。"先挑必然能出结论的线索"。

## Key Takeaways
1. "说法正确/错误"：通读→按选项回扣精读。
2. 题干短看差异，题干长观大要。
3. 先判断确定的线索，排到二选一再精比。
4. 科技类：常识 > 拆词 > 同构排除（最后一步）。
5. 题做完后，查清不熟的常识并记下。
