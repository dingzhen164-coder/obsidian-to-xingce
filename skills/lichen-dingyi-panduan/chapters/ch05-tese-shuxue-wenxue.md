# 第五章：特色定义积累（二）——数学类定义 · 文学与言语类定义 · 常识的积累路径

## Core Idea
**数学类定义：先看带数字的选项，算对就选；文学与言语类：靠常识、哪里懂看哪里，多定义时用"另一个定义"反着排。** 两类底层一致——先找最容易落实、最容易验证的落点。

## Frameworks Introduced
- **数学类三条方法**：①优先看带数字/带公式的选项（命题人写公式就是希望你算）；②算对直接选，不必对比择优；③涉及除法（A÷B）时看分子分母同增/同减的**变动幅度**。
  - How：都增加→看分子增幅是否更大；都减少→看分母减幅是否更大。
  - 例：价值＝功能÷成本。成本不变功能增加→价值升；成本降功能不变→升；功能略降成本大降→升；成本略升功能大增→升。
  - 郁闭度＝树冠投影面积÷林地总面积：0.3与3万公顷→总面积10万公顷。森林蓄积量（活立木）≤立木蓄积量（活＋枯）。
- **文学与言语类三条思路**：①靠常识（词义、词性、语法结构、修辞——会就是送分）；②哪里懂看哪里；③多定义时，被问的看不懂就看另一个，反着排。
- **"用另一个定义反着排"实例**：问分系式→用"分别搭配"排；问连文→用变文排；问述补→用述宾排；问动趋式把字句→用光杆动词式排。
- **语法结构要点**：
  - 领主属宾句：主语是"领有"一方，宾语是"隶属"一方，动词与主语无直接语义关系（"他头顶上飞过一只鸟"不是——鸟不隶属于头）。
  - 述补 vs 述宾：述补＝述语（动作）在前、补语说明动作的情况/结果/处所/数量/时间；找述语时先看前面是不是动作词（"力度刚好"名词开头排除）。
  - 旋造：同一语句中故意互换两个短语的语素，造成超常组合。
  - 变文：避重而用同义词；连文：本要表达甲而连带说到乙，突出其中一个词的意义。
  - 起兴：先言他物以引起所咏之辞，用于开头。
  - 另有使动/意动、缩喻、正偏结构。
- **常识的积累路径**：词义（相同/相对/相反）、词性、语法结构（并列/偏正/正偏/述补/述宾）、修辞手法、名人名句与典故——**在做过的题里学**；命题人偏爱的人物、语法点会重复考（《史记·淮阴侯列传》、述补→动补）。补一个范畴比记一道题有用。

## Key Concepts
- **色温**：加热到 N(K) 时绝对黑体的发光光谱成分；0K=-273℃（2727℃=3000K）。
- **郁闭度**：最大值1，与气温日变化负相关、与相对湿度正相关。
- **对立互补命题**：两个结构基本相同的句式中含有两对或以上对立概念。
- **烈士（曹操《龟虽寿》）**：有雄心壮志的有志之士，与今义不同。

## Anti-patterns
- 数学类定义里先做定性对比择优，而不先算。
- 看到诗句就放弃用多定义对比法。
- 只记题不补范畴。

## Worked Example
(2023联考)价值工程"价值＝功能÷成本"，四个选项逐一把功能、成本的升降方向标出，比值只看谁变得快：①成本不变功能增加→升；②成本降→升；③功能略降、成本大降→升（分母减幅更大）；④成本略升、功能大增→升（分子增幅更大）→ 4项，选D。

## Key Takeaways
1. 带数先算，算对即选。
2. 分子分母同向变动→比幅度。
3. 文学类：会就是送分，不会看另一个定义反着排。
4. 常识在题里学，补齐整个范畴。
5. 难题正确率多在30%–50%，难是好事。
