# 第六章：真题带练与复盘——十五道真题的方法复盘 · 组卷小结 · 定义痛点收官

## Core Idea
用一份2022–2026年的十五题组卷验证全套方法；复盘的取舍：**简单题不复盘，纠结和做错的才复盘**；考场目标是**"六道稳拿、四道半猜、对八道"**，遇到不会的选一个就走。

## Frameworks Introduced
- **组卷小结（题号→注意点）**：
  - 例1 分权时序64%：拆词；例2 需求价格弹性48%：主客体（数量、"其"、价格先变需求量后变）；例3 种间互作44%：表述宽泛不优先看；例4 游戏/规则游戏/合作游戏37%：总分定义、否定词、两个以上；例5 商品动销率64%：先做定量分析；例6 意思主义/表示主义36%：主客体、同构；例7 肌肉记忆51%：先天/后天、条件反射；例8 半公开信息源37%：公开/秘密、黑灰白色；例9 推理句/因果句11%：对比差异、**时态**；例10 适应性绩效78%：主体须个体；例11 电参量：哪个简单看哪个；例12 部落计数54%：**方向**；例13 生理/病理性衰老45%：常识；例14 选矿79%：表述宽泛不优先看；例15 连接号48%：哪个简单看哪个、常识。
  - 规律：低正确率题多败在**方法**（对比差异、总分定义、否定词、时态）；高正确率题多败在**没看清字面**。最常用三把工具：**拆词、主客体、哪个简单看哪个**。
- **四件额外要学的事**：①时态——已经发生（因果句）vs 尚未发生（推理句）；②方向——数位高低可能反直觉；③幅度——比值同增同减看谁变得快；④常识——诗人、典故、物理概念都在射程内。
- **二择大失败的四步**：拆词抓本质 → 对比差异（再回题干看差异点在不在要求里）→ 看同构 → 闭眼选一个往下走（选了就别回头）。
- **四大痛点收官**：字多读得慢→问什么看什么、什么简单看什么；读不懂→找能读懂处、对比两定义；抓不住→猜词/主客体/前提条件/方式目的/原因结果/解释说明；二择失败→上面四步。

## Key Concepts
- **选矿**：把有用矿物与脉石分开；"挑选优质翡翠原石"只是挑，没有"分开"，故没体现。
- **部落计数**：右边是高位（■>□>◆>◇），左边是低位（◇>◆>□>■）；先判高位再判低位。
- **连接号**：短横线5种用法（化合物名/编号、号码与阿拉伯数字年月日、复合名词、产品型号、拼音/外来语）；一字线或浪纹线标起止。"2025年8月10日-20日"用短横线表起止→错。
- **因果句 vs 推理句**：因果句是已发生事件的成因；推理句是基于前提推可能性/必然性（预测）。

## Anti-patterns
- 想把不会的题也做对而耗时纠结（10分钟做成15–18分钟）。
- 简单题反复复盘。
- 指望考场上两三分钟弄懂二十年没学会的常识。
- 选了又回头。

## Worked Example
(2026联考)例9因果句11%：两段定义都长且抽象——换思路：多定义读不懂，就把两个定义并排对比。能用的只有各自的"核心功能"：推理句＝论证观点/**预测可能性**（指向将来），因果句＝**解释**现象成因（结果已发生）。时态是题眼：①"就应承担"是推测；②"明年可能改种"是预测；④"肯定湿了"是由雨声作推断，且因果要由果索因，不是因果句；只有③"网站瘫痪了3小时"是已发生事件的成因 → 仅1项，选A。
  - 时态词：已发生——"了、曾、已经"；未发生——"将、会、可能、应、肯定"。

## Key Takeaways
1. 6道稳拿＋4道半猜，不要让心态崩在"十道全稳"上。
2. 时间花在纠结上最亏——选一个就走，把时间留给数量关系、政治常识。
3. 真题考过的未来还考（灰色文献→半公开信息源；述补→动补）；定义不考，概念、常识、诗句也考。
4. 复盘自己：这个字放了七八遍都没看见，是思维方式问题，不是眼神问题。
5. 最重要两件事：身体健康；活得开心。
