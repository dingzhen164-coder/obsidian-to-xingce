# 定义判断速查表（决策规则版）

## 一、做题流水线
| 步骤 | 做什么 | 来源 |
|---|---|---|
| 1 看提问 | 选是/选非；定义词；"只体现"→先排另一类 | ch1 ch3 |
| 2 看题干 | 只读定义所在句；多定义→问谁看谁 | ch1 ch3 |
| 3 抓关键信息 | 拆词 → 主客体 → 前提条件 → 方式目的 → 原因结果 → 否定词/反复出现的词 | ch1 ch2 |
| 4 看选项 | 简单题直接选；难题排错、对比择优；明显违背的直接排 | ch1 |
| 5 二择 | 拆词→对比差异→同构→闭眼选一个，**不回头** | ch6 |

## 二、决策规则（When X → do Y）
- 题干读不懂 → 读得懂的地方先看；看不懂 A 看 B；两个定义并排找差异（ch6）
- 选项主体不符（如政府≠企业、事业单位≠企业、个人≠组织）→ 直接排，其余不看（ch1）
- 选项出现"某地/某市/某省"采取行为、或涉及公共事务管理 → 主体视为政府（ch1）
- 定义含"在……前/中/后"→ 只看选项行为是否落在该区间（ch2）
- 定义含"非/不/未"→ 违反的选项直接排（ch2）
- 定义含"直接/间接、含蓄"→ 比谁多出中间环节（ch2）
- 定义词含"替代/互动/歧视/变化/若干"→ 先标数量/双向/前后两状态要求，再逐项点数（ch2）
- 定义句读懂 → 不读解释；读不动或选不出唯一答案 → 再读"即/核心/也就是说"后面（ch2）
- 多定义被问的读完选不出 → 读另一个，只抓不同（ch3）
- 总分类定义 → 子定义必须先满足母定义（ch3）
- 设问"说法正确/错误"→ 通读后按选项定位；短题抓差异，长题观大要；先判必然线索（ch4）
- 科技类读不懂 → 积累常识 > 拆词 > 同构排除（最后）；物理 vs 化学：有无新物质生成（ch4）
- 数学类 → 先看带数/带公式选项，算对即选；比值同增同减看幅度谁大（ch5）
- 文学类 → 靠常识，哪里懂看哪里；被问的看不懂就用另一个定义反着排（ch5）
- 题涉及时间方向 → 分清已发生（了/曾/已经）与未发生（将/会/可能/应/肯定）（ch6）
- 数位/排序规则题 → 先复述规则，当心方向反直觉（ch6）

## 三、阈值与默认
| 项 | 值 |
|---|---|
| 目标 | 10 分钟、正确率 80%（10 题对 8） |
| 稳拿 | 6 道；其余 4 道多数进入二选一（50%） |
| 国考三年 55 题 | 简单(>70%) 31 / 中等 23 / 难(<40%) 1 |
| 考场纠结 | 不会就选一个走，不回头 |
| 复盘 | 简单题不复盘；纠结与做错的才复盘 |

## 四、不优先看 vs 必看
| 不优先 | 例子 |
|---|---|
| 概念宽泛 | 农业、各种特殊因素 |
| 表述抽象 | 意境、韵味、审美 |
| 冷门生僻 | 报告文学 |

必看：定义词、主客体、前提条件、方式目的、**反复出现的词**。

## 五、Tells & smells
- 四个选项长得一模一样（"因为……所以……"）→ 差异在时态/语气词，不在主干。
- 选项里主体为"某市行政服务中心"之类 → 事业单位，不是企业。
- 选项里有数字/公式 → 命题人希望你算。
- 成对定义只差一个字（非/未/无）→ 差异点就是答案。
- 定义词里带"物理/化学" → 回忆初高中知识。
