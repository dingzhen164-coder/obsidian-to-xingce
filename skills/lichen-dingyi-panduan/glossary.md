# 术语表（按拼音/笔画粗排）

**变文** — 为避重在相邻句用同义词表达相同意义的古汉语修辞 (Ch5)
**分类数据 / 顺序数据** — 均为非数字型数据；分类只归入某一类别，顺序归入"有序类别"(Ch4)
**对比差异** — 多定义/二选一时只抓不同之处，相同表述无效 (Ch3, Ch6)
**方式与目的** — 引导词"通过/利用"与"以/以达到"(Ch2)
**母子（总分类）定义** — 总括概念分子类，子必须先满足母 (Ch3)
**机会成本 / 显成本 / 隐成本** — 放弃的最大利益；购买他人要素支出；自有要素价格 (Ch4)
**解释说明** — 定义句读不懂/选不出答案时才读，引导词"即/核心/也就是说"(Ch2)
**郁闭度** — 乔木树冠地面投影面积÷林地总面积，最大值1 (Ch5)
**连文** — 本要表达甲而连带说到乙，突出其一的修辞 (Ch5)
**连接号** — 短横线、一字线、浪纹线；短横线用于编号/号码/型号等，一字线表起止 (Ch6)
**领主属宾句** — 主语"领有"、宾语"隶属"，动词与主语无直接语义关系 (Ch5)
**拆词法** — 拆定义词定位关键信息 (Ch1)
**前提条件** — "在……前/中/后"，选项行为须落入区间 (Ch2)
**起兴** — 先言他物以引起所咏之辞 (Ch5)
**旋造** — 故意互换两短语语素造成超常组合 (Ch5)
**同构选项排除** — 找结构相同的选项，选"不属于"时选孤立项（慎用）(Ch4)
**述补 / 述宾** — 述语+补语(补说情况结果处所)；述语+宾语(支配对象)(Ch5)
**推理句 / 因果句** — 推理句预测可能性(将来)；因果句解释成因(已发生)，时态是题眼 (Ch6)
**问谁看谁** — 多定义设问指向哪个就先读哪个 (Ch3)
**物理 vs 化学变化** — 有无新物质生成 (Ch4)
**行政机关 / 权力机关 / 立法机关 / 司法机关 / 事业单位** — 政府类主体范围，须记忆 (Ch1)
**主客体** — 主语/宾语；政府(非营利)/企业(营利)/个人 (Ch1)
