# 常识判断 解题

> **被 xingce-jiexi-all 调度、或用户说"给第N季生成解析 / 只做某板块"时**：直接跳到本文件末尾「被 xingce-jiexi-all 调度时」一节照做。如果加载进来的内容里看不到那一节，只用一次 Read 读本 SKILL.md 的末尾部分，不要再找别的文件。

## 适用题型
政治（理论、时政）、法律（宪法、民法、刑法、行政法、诉讼法）、经济（宏观、微观、金融）、历史（中国古代、近现代、世界史）、人文（文学、艺术、文化常识、成语典故）、科技（物理、化学、生物、航天、信息技术）、地理（自然、人文、中国地理）。常识判断考的是**知识点**，本 skill 管的是**怎么逐项判断、怎么写解析**，不罗列知识点。

## 解题步骤（拿到一道题的 SOP）
1. **圈设问**：选正确 / 选错误 / 不属于 / 对应正确，先标出来。常识题"选错误"很常见，别看反。
2. **定领域**：每个选项各考哪个领域、哪个知识点（常识题常常四个选项四个领域，要分开判断）。
3. **逐项判断**：每项都给出**依据**——关键事实（人物、朝代、时间、主体、数值、法条要件、科学原理），写清对在哪 / 错在哪个细节。
4. **锁定答案**：选错误题找唯一错项，选正确题找唯一对项；一时找不出，就按「核心框架」里的常见偷换逐个检查。
5. **扩展**：围绕答案补 1～2 个同类高频考点（每条一行）。

## 核心框架（遇到 X → 用 Y）
- 人物、作品、朝代、流派一起出现 → 查**张冠李戴**：作者—作品—朝代—流派四要素逐一对。
- 带时间、年份、先后顺序 → 查**时间错位**：先定朝代 / 年代，再对事件。
- 法律题 → 按**主体资格 → 构成要件 → 例外 / 但书**的顺序判断；注意年龄、责任能力、程序时限。
- 政府、机构职能题 → 查**主体偷换**（哪个机关有这个权力）。
- 科技、生活现象题 → 先说**现象**，再说**原理**，查"原理张冠李戴""因果颠倒"。
- 地理题 → 按**成因链**判断（纬度 / 海陆 / 地形 / 洋流 → 气候 → 物产、人文）。
- 选项有"一切、都、必然、只有、完全" → 查**绝对化表述**，常是错项。
- 两个相近概念 → 查**概念混淆**，写出区别性一句话（见下方易混速查）。
- **时政、最新数据题** → 你的知识可能过时：以正确答案为锚来解释，**不补充自己不确定的新数据、新表述**，在解析末尾标"（时政，以官方最新表述为准）"。

## 解析写法
**每个选项都要写依据**，并落到题干 / 选项原文的具体词句（引用原文里的人物、年份、法条要件、现象描述），用本 skill 的术语（张冠李戴、时间错位、主体偷换、绝对化、概念混淆…），错项写明错在哪个细节；不确定的事实写 `⚠ 待核对：<哪一点>`，不编年份、数据、法条条号。

```
【答案】X
【题型】法律·民法 / 历史·古代史 / 科技·物理 ……
【逐项】
  A ✗：<关键事实>——错在<主体 / 时间 / 人物 / 程度 / 原理 / 绝对化>
  B ✓：<关键事实>——对
  C ✗：……
  D ✗：……
【考点】一句话说清本题考的知识点
【扩展】① 同类高频考点……　② ……（最多 2 条）
【易混】X vs Y：区别一句话（没有就省略）
【易错】我选 Y 错在……（我答对时省略）
```

## 题型索引 / 易混速查
| 易混概念 | 区别（一句话） |
| --- | --- |
| 行政复议 vs 行政诉讼 | 复议向上级行政机关申请，诉讼向法院起诉 |
| 管制 vs 拘役 | 管制不关押、限制自由；拘役就近关押，1 个月以上 6 个月以下 |
| 正当防卫 vs 紧急避险 | 防卫针对不法侵害人；避险是损害第三方合法权益来避开危险 |
| 财政政策 vs 货币政策 | 财政靠收支（税收、支出），货币靠央行（利率、准备金、公开市场） |
| 通货膨胀 vs 通货紧缩 | 物价持续上涨 vs 持续下跌 |
| 反射 vs 折射 | 光在同一介质界面返回 vs 进入另一介质时方向改变 |
| 物理变化 vs 化学变化 | 有没有生成新物质 |
| 天干地支 | 天干 10、地支 12，60 年一轮回 |

（速查只放高频易混对；遇到表里没有的，按「核心框架」判断，不必补进来。）

## 单独答题时（不经过 xingce-jiexi-all）

用户在对话里直接问一道题时：
- **用户给了正确答案**：以答案为锚，按本 skill 的「解题步骤」和「解析写法」讲，**不要联网**。
- **没给答案**：先按本 skill 的方法**独立作答**，写出理由和把握程度（有把握 / 两项之间犹豫，并说明在哪两项之间）。
- **默认不联网搜答案**。只有用户要求核对时才搜，**最多搜 1 次**；来源互相矛盾就停止搜索，给出自己的判断并注明"来源不一致"。每读一个网页都要花大量 token。
- 输出照样用「解析写法」的格式。

## 被 xingce-jiexi-all 调度时

被总调度 skill 派来处理某一季的本板块时，按下面流程**直接把解析写进板块 md 文件**，不在对话里输出长篇解析。

`<jiexi>` 指 `xingce-jiexi-all/scripts/jiexi.py`（和本 skill 在同一个 skills 目录下）。路径一律加英文双引号；命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。

**直接开始，不要摸索**：用户说“给第N季生成解析 / 只做某板块”时，直接运行下面的命令，`<季>` 写季数（如 `36`）即可，脚本会自己找到目录。**不要** ls / find / grep 库里的文件，**不要**读 jiexi.py 源码、board-map.md、`projects/` 等目录，**也不要打开板块 md 文件本身**——题目、答案、截图路径 `next` 都会打印出来，写入用 `write`。

**Windows PowerShell**：中文输出会乱码，每条 python 命令前固定加 `[Console]::OutputEncoding=[Text.Encoding]::UTF8;`（同一行），不用先试一次再加。

1. 取一批题：`python "<jiexi>" next <季> 常识判断 [--mode 错题|全部]`
   输出里有板块文件路径、本批题号、题干、选项、正确答案、我的答案，以及截图完整路径。有 `[截图]` 的必须打开截图看。**看图预算**：原图只读 1 次；看不清时最多再读 2 次局部放大；**不要安装任何软件包**（pip install 等），系统里没有的工具就不用；还是看不清就写 `⚠ 待核对：截图看不清`，接着做下一题。
2. 按上面的「解题步骤 / 核心框架」解这一批题，遵守：
   - **以正确答案为锚**：推导必须落到给出的正确答案；推不出来就写一行 `⚠ 待核对：<卡在哪一步>`，不要硬编；
   - 我答错时，点出我选的选项错在哪；
   - **真用上面的解题方法**：按「解析写法」逐段写，每段落到原文的句子 / 词语，用本 skill 的术语，不要只贴术语名。
3. 把这批解析写进 `next` 打印的临时文件（`<第N季目录>/.jiexi-tmp.md`），每题以 `=== 题号` 开头：
   ```
   === 36
   【答案】B
   【逐项】……
   === 37
   ……
   ```
   然后写入板块 md：`python "<jiexi>" write <季> 常识判断`
   （脚本会给每行加 `> `，只写空的复盘栏，不会覆盖已有笔记。）
4. 重复 1–3，直到 `next` 显示“没有待解析的题”。
5. 检查格式：`python "<jiexi>" check <季> 常识判断`，有 ❌ 就按提示修好。
6. 回报一句话：写入了几题、哪些题标了待核对。

### 省 token 规则
- **只用本 SKILL.md**：本 skill 没有章节和 cheatsheet，不要去找别的文件。
- **不联网**查知识点；拿不准就标 `⚠ 待核对`。
- 【扩展】最多 2 条、每条一行；【易混】没有就省略。

**不能运行 python 的环境**，可以直接编辑板块 md，但必须遵守：
- 只改 `> [!note] 复盘` 下面、该题 `---` 之前的内容；
- 每一行都以 `> ` 开头，空行写成 `>`；
- 复盘栏已有内容的题不要动（只有 `- 错因：` `- 考点：` `- 下次怎么做：` 这类空模板的不算有内容，写解析时把这几行模板原样保留在解析下面）；
- 不改题干、选项、答案行、frontmatter 和速览表。
