# 行测模考 · 一键解析（总调度）

本 skill **只负责调度，不含任何解题方法**。解题方法全在各板块自己的 skill 里；板块和 skill 的对应关系全在 `板块映射.md` 里。改方法 → 改板块 skill；换/加 skill → 改映射表；本文件不用动。

## 一、确认任务

从用户的话里确定三件事，没说的用默认值，不要反复追问：

| 项 | 默认 | 例子 |
|---|---|---|
| 季数目录 | 必须有 | “第36季” → `行测/FB模考试卷复盘/板块复盘/第36季/` |
| 范围 | 映射表里的“默认范围”（一般是错题） | “全部题都要” → `全部` |
| 板块 | 映射表里配了解题 skill 的所有板块 | “只做论证和形式逻辑” |

## 二、看进度

```
python "<本skill目录>/scripts/jiexi.py" status "<第N季目录>"
```

它会打印并写入 `<第N季目录>/解析进度.md`：每个板块用哪个 skill、还剩哪些题。**是否做过完全以复盘栏有没有内容为准**，所以上次中断后再运行，自然从断点继续，不会重复消耗。

路径含中文和括号，一律加英文双引号；Windows 上 `python` 不可用时换 `py`。

## 三、逐板块、逐批解析

对每个要做的板块，**一次只处理一个板块**：

1. **加载这个板块的解题 skill**（名字取自映射表）。只读这一个，不要把其它板块的 skill 也读进来。
2. **取一批题**：
   ```
   python "<本skill目录>/scripts/jiexi.py" next "<第N季目录>" <板块> [--mode 错题|全部]
   ```
   输出里有题干、选项、正确答案、我的答案，以及截图的完整路径。有 `[截图]` 的题（图形、公式、图表、资料分析材料）必须打开截图看，文字版会缺字。
3. **按解题 skill 的方法解这一批题**，遵守下面“解析规则”，把结果写进一个临时文件（如 `<第N季目录>/.jiexi-tmp.md`），格式：
   ```
   === 36
   （第36题的解析，多行随意，不用加 “> ”）
   === 37
   （第37题的解析）
   ```
4. **立刻写回**：
   ```
   python "<本skill目录>/scripts/jiexi.py" write "<第N季目录>" <板块> "<临时文件>"
   ```
   脚本只往空的复盘栏里写，已有内容（包括你自己写的笔记）不会被覆盖。
5. 重复 2–4，直到 `next` 显示“没有待解析的题”，再换下一个板块。

**有子代理/子任务功能时**（Claude Code 的 Task、opencode 的 subagent 等）：每个板块交给一个新的子代理，只告诉它“板块名、季数目录、解题 skill 名、本 skill 的第三节和解析规则”。多个板块可以依次派发，子代理之间互不污染上下文。没有这类功能就在当前对话里串行做。

**映射表里没有解题 skill 的板块**：直接跳过，不要自己发挥解题。

## 四、解析规则（对所有板块统一生效）

- **以正确答案为锚**：题目给出的正确答案就是标准答案，解析要推导到它。推不出来时，不要硬编，在该题解析里写一行 `⚠ 待核对：……（卡在哪一步）`，然后继续下一题。
- **结合我的答案**：我答错时，要点出我选的选项错在哪里，或者我可能掉进了哪个陷阱。
- **格式听板块 skill 的**：解析写成什么结构，由板块 skill 决定；板块 skill 没规定时，用 `【答案】`、`【思路】`、`【易错】` 三段。
- **被调度时，板块 skill 不要自己改文件**：即使板块 skill 本来的流程是自己改 md，被本 skill 调用时也只产出解析文字，统一由 `jiexi.py write` 写入。
- 不改题干、选项、答案行，不动 frontmatter 和速览表。
- 图形推理、依赖图表的资料分析题，读图没有把握时，也标 `⚠ 待核对`。

## 五、出错与续跑

- API 超时、限流、对话中断：什么都不用修，重新运行本 skill 即可。已写入的题会被跳过。
- 某一题反复失败：写一行 `⚠ 待核对：解析失败` 进去占位，保证进度往前走。
- 要重做某题：先在 md 里清空它的复盘栏（只留 `> [!note] 复盘` 和下面一行 `>`），再运行；或者在 `write` 时加 `--force`（会覆盖已有笔记，加之前必须提醒用户）。

## 六、汇报

全部做完（或本次停下）时，再运行一次 `status`，用几句话告诉用户：做了哪些板块、每个板块写入多少题、哪些题标了待核对、哪些板块因为没有解题 skill 被跳过。

## 附：给板块 skill 的接入约定

想让一个板块 skill 能被本 skill 调度，只要它满足：

- **输入**：一道或几道题的题干、选项、正确答案、我的答案（有截图就附截图路径）；
- **输出**：每道题一段解析文字；
- 在它的 SKILL.md 里加一句：“被 xingce-jiexi-all 调用时，只输出解析文字，不要自己修改文件。”

然后在 `板块映射.md` 里填上它的名字即可。
