# 行测模考 · 一键解析（总调度）

本 skill **只负责派活和验收，不含任何解题方法，也不自己写解析**。

- 解题方法和解析写法：在各板块自己的 skill 里；
- 哪个板块用哪个 skill：在 `板块映射.md` 里（13 个名字已定好，新 skill 照名字建好就会被自动发现）；
- 读写板块 md 的固定操作：在 `scripts/jiexi.py` 里。

下文 `<jiexi>` 指本 skill 目录下的 `scripts/jiexi.py`。路径含中文和括号，一律加英文双引号；命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。

## 一、确认任务

从用户的话里确定三件事，没说的用默认值，不要反复追问：

| 项 | 默认 | 例子 |
|---|---|---|
| 季数目录 | 必须有 | “第36季” → `行测/FB模考试卷复盘/板块复盘/第36季/` |
| 范围 | 映射表里的“默认范围”（一般是错题） | “全部题都要” → `全部` |
| 板块 | 所有已创建解题 skill 的板块 | “只做论证和形式逻辑” |

## 二、看进度

```
python "<jiexi>" status "<第N季目录>"
```

打印并写入 `<第N季目录>/解析进度.md`：每个板块的解题 skill、是否已创建、还剩哪些题。**是否做过完全以复盘栏有没有内容为准**，所以上次中断后再运行，自然从断点继续。

状态为“跳过（… 尚未创建）”的板块不做，不要自己发挥解题。
（如果你的 skill 列表里明明有这个 skill，只是不在同一个 skills 目录下，也可以照常派发。）

## 三、逐板块派发

对每个“未开始/进行中”的板块，**一次只处理一个板块**，派给它的解题 skill：

> 加载 `<解题skill>`，按其中「被 xingce-jiexi-all 调度时」一节，处理 `<第N季目录>` 的 `<板块>` 板块，范围 `<错题|全部>`。jiexi.py 路径：`<jiexi 完整路径>`。

- **有子代理/子任务功能时**（Claude Code 的 Task、opencode 的 subagent 等）：每个板块开一个新的子代理，把上面这句话连同季数目录、jiexi 路径交给它。子代理之间上下文互不污染，一个板块出错不影响别的板块。**逐个派发，不要并行**——并行会同时触发限流。
- **没有子代理功能时**：在当前对话里加载该板块 skill，照它的调度流程做；做完一个板块，后面不再引用它的内容，再加载下一个板块的 skill。**不要一次把多个板块 skill 都读进来。**
- 板块 skill 里如果还没有「被 xingce-jiexi-all 调度时」一节（旧 skill 没加），按 `板块skill模板.md` 里那一节的流程代为执行：用该 skill 的解题方法解题，用 `jiexi.py next / write` 取题和写入。

板块 skill 会自己把解析写进板块 md（`next` 取一批 → 解题 → `write` 写回 → 直到做完）。

## 四、验收

每个板块做完后立刻检查：

```
python "<jiexi>" check "<第N季目录>" <板块>
```

- 全 ✅：进入下一个板块。
- 有 ❌：按提示修复（最常见的是复盘栏里有行没以 `> ` 开头、或中间有空行把 callout 截断了——把它改成 `>` 即可）。修不好就告诉用户，不要删题。

## 五、统一规则（所有板块 skill 被调度时都要遵守）

- **以正确答案为锚**：推导必须落到给出的正确答案；推不出来时写一行 `⚠ 待核对：……（卡在哪一步）`，不要硬编，然后继续下一题。
- **结合我的答案**：我答错时，点出我选的选项错在哪。
- 有截图的题必须看截图；图形推理、依赖图表的资料分析题，读图没把握也标 `⚠ 待核对`。
- 只写复盘栏；不改题干、选项、答案行、frontmatter、速览表；复盘栏已有内容的题不动。

## 六、出错与续跑

- API 超时、限流、对话中断：什么都不用修，重新运行本 skill 即可，已写入的题会被跳过。
- 某一题反复失败：写一行 `⚠ 待核对：解析失败` 占位，保证进度往前走。
- 要重做某题：在 md 里清空它的复盘栏（只留 `> [!note] 复盘` 和下面一行 `>`），再运行；或 `write` 时加 `--force`（会覆盖已有笔记，加之前必须提醒用户）。

## 七、汇报

全部做完（或本次停下）时再运行一次 `status`，用几句话告诉用户：做了哪些板块、每个板块写入多少题、哪些题标了待核对、哪些板块因为 skill 尚未创建被跳过。

## 附：新增 / 修改板块 skill

- **新增**：照 `板块skill模板.md` 写，文件夹名用 `板块映射.md` 里定好的名字，放在同一个 `skills/` 目录下。不用改本 skill 和映射表。
- **修改解题方法**：只改那个板块 skill 的「解题方法 / 解析写法」，「被 xingce-jiexi-all 调度时」一节保持不动。
- **换成另一个 skill**：只改 `板块映射.md` 里那一行的名字。
