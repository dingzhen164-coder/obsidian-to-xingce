## 二、新写的板块 skill：复制下面的模板

1. 在 `skills/` 下建文件夹，名字**严格用** `board-map.md` 里给的名字（如 `xingce-shuliang`）；
2. 新建 `SKILL.md`，复制下面代码块里的全部内容，把 `<>` 里的换掉，写好“解题方法”；
3. 完成。总调度会自动发现它，不用改任何别的文件。

~~~~markdown
---
name: <照board-map.md里的名字，如 xingce-shuliang>
description: 行测<板块名>题的解题方法与解析写法。用户让解析/讲解/复盘<板块名>题（<列几个典型题型关键词>），或 xingce-jiexi-all 调度<板块名>板块时使用。
---

# <板块名> 解题

## 解题方法

<这里写你的方法：题型识别、每类题的步骤、秒杀技巧、常见陷阱……以后有新 idea 就改这里>

## 解析写法

每道题的解析按下面的结构写（可按需要改）：

【答案】<正确答案>
【题型】……
【思路】……
【易错】我选 X 错在……（我答对时可省略）

## 被 xingce-jiexi-all 调度时

被总调度 skill 派来处理某一季的本板块时，按下面流程**直接把解析写进板块 md 文件**，不在对话里输出长篇解析。

`<jiexi>` 指 `xingce-jiexi-all/scripts/jiexi.py`（和本 skill 在同一个 skills 目录下）。路径一律加英文双引号；命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。

1. 取一批题：`python "<jiexi>" next "<第N季目录>" <板块名> [--mode 错题|全部]`
   输出里有板块文件路径、本批题号、题干、选项、正确答案、我的答案，以及截图完整路径。有 `[截图]` 的必须打开截图看。
2. 按上面的「解题方法」解这一批题，遵守：
   - **以正确答案为锚**：推导必须落到给出的正确答案；推不出来就写一行 `⚠ 待核对：<卡在哪一步>`，不要硬编；
   - 我答错时，点出我选的选项错在哪。
3. 把这批解析写进一个临时文件（如 `<第N季目录>/.jiexi-tmp.md`），每题以 `=== 题号` 开头：
   ```
   === 36
   【答案】B
   【思路】……
   === 37
   ……
   ```
   然后写入板块 md：`python "<jiexi>" write "<第N季目录>" <板块名> "<临时文件>"`
   （脚本会给每行加 `> `，只写空的复盘栏，不会覆盖已有笔记。）
4. 重复 1–3，直到 `next` 显示“没有待解析的题”。
5. 检查格式：`python "<jiexi>" check "<第N季目录>" <板块名>`，有 ❌ 就按提示修好。
6. 回报一句话：写入了几题、哪些题标了待核对。

**不能运行 python 的环境**，可以直接编辑板块 md，但必须遵守：
- 只改 `> [!note] 复盘` 下面、该题 `---` 之前的内容；
- 每一行都以 `> ` 开头，空行写成 `>`；
- 复盘栏已有内容的题不要动（只有 `- 错因：` `- 考点：` `- 下次怎么做：` 这类空模板的不算有内容，写解析时把这几行模板原样保留在解析下面）；
- 不改题干、选项、答案行、frontmatter 和速览表。
~~~~
