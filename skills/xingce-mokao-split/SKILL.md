# 行测模考试卷 → 板块复盘笔记

## 目录约定

仓库里的结构是：

```
行测/FB模考试卷复盘/
├── 模考试卷/      ← 原始 PDF，如 2027年国考第三十六季行测模考大赛（行政执法类）.pdf
└── 板块复盘/
    └── 第36季/    ← 本 skill 的输出（季数从文件名“第X季”自动识别）
        ├── 00-第36季总览.md
        ├── 01-政治理论.md … 13-资料分析.md
        └── attachments/   ← 题目/材料截图，命名 S36-Q066.png、S36-M111-115.png
```

## 工作流程

1. **确认输入**：拿到 PDF 的完整路径。用户只说“第37季”之类时，到 `模考试卷/` 里找文件名含该季数的 PDF；找到多个就问用户是哪一份。

2. **检查环境**（只在第一次或报错时做）：
   ```
   python -c "import pymupdf"
   ```
   报错就执行 `pip install pymupdf`（Mac 用 `pip3`）。命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。

3. **运行脚本**（路径含中文和括号，必须加英文双引号）：
   ```
   python "<本skill目录>/scripts/split_mokao.py" "<PDF完整路径>"
   ```
   可选参数：
   - `--out "<目录>"`：不用默认输出目录时指定
   - `--snap-all`：每道题都附截图（默认只给数量关系、图形推理、资料分析材料，以及含图片/公式的题截图）
   - `--force`：覆盖已存在的板块文件

4. **核对控制台报告**，逐项检查：
   - “共解析 N 题”应与试卷总题数一致（国考行政执法类 130 题、地市级 130 题、副省级 135 题）且编号连续。不一致时，打开 PDF 对应页找原因再告诉用户，不要硬凑。
   - 各板块题号区间是否合理（常见：言语里 逻辑填空在前，语句排序通常 1–2 题；判断推理顺序为 图形 → 定义 → 类比 → 逻辑，一拖五在最后）。
   - 有“没解析到正确答案”的警告要告诉用户。

5. **修正分类**（仅在确实分错时）：分类靠题干关键词，偶尔会错。发现某题分错板块时，把该题整块（从 `### 题号.` 到下一个 `---`）剪切到正确的板块文件，并同步更新两边文件顶部的表格和 frontmatter 里的题数/作答/正确/正确率。

6. **汇报**：用几句话告诉用户输出位置、各板块题数和正确率，重点点出错题最多的板块。

## 重要约束

- **绝不默认覆盖**：板块文件里可能已经写了复盘笔记。脚本遇到已存在的文件会跳过并提示；只有用户明确说“重新生成/覆盖”时才加 `--force`，且加之前提醒会丢失已写的笔记。
- 不要自己重写脚本生成的题目文字去“润色”——题干要和试卷一致。
- 公式、分数、角度、图形在 PDF 里是图片，文字版会缺字（如“完成任务的 ，”），以截图为准，这是正常现象，不用修。

| 大题 | 规则 | 板块 |
|---|---|---|
| 一、政治理论 | 整部分 | 政治理论 |
| 二、常识判断 | 整部分 | 常识判断 |
| 三、言语理解 | 题干含“重新排列/语序正确” | 语句排序 |
| | 含“依次填入”，或“填入横线”且选项都是短词（≤8字） | 逻辑填空 |
| | 其余（主旨、意图、标题、细节、接语、语句填入） | 中心理解 |
| 四、数量关系 | 整部分 | 数量关系 |
| 五、判断推理 | 前面有共用材料的题 | 一拖五 |
| | 含“填入问号处/分为两类/正方体/截面/展开图/多面体”等，或选项就是 A/B/C/D 字母 | 图形推理 |
| | 含“定义” | 定义判断 |
| | “A：B” 短词对，或“对于…相当于” | 类比关系 |

## 输出格式说明

每个板块文件：frontmatter（来源、季数、题数、作答、正确、正确率、tags）→ 题号速览表（点击跳转）→ 资料/一拖五的共用材料 → 每道题：

```markdown
### 36. ❌
（截图，如有）
题干……唯有回归____、循循善诱的教育模式……

- **A.** 对症下药
- **B.** 因材施教
…
> [!check]- 答案        ← 默认折叠，重做时不会先看到答案
> 正确答案：**B**　我的答案：**C**　错误

> [!note] 复盘         ← 内容留空，由其它 skill（如写解析的 skill）往里填
>
```

往“复盘”里写内容时，每一行都要以 `> ` 开头，写在 `> [!note] 复盘` 这一行下面、下一个 `---` 之前，才能留在 callout 里。

✅ 正确　❌ 错误　⚪ 未作答
