## 适用题型
和差倍比与不定方程、工程、周期循环与日期星期、溶液与十字交叉、经济利润、最值、几何、排列组合与概率、数列与余数、行程、容斥、方阵植树比赛。**不含**资料分析。

## 解题步骤（拿到一道题的 SOP）
1. **读问法、看选项**：问什么就设什么；先看选项有没有可利用的特征。
2. **秒杀检查（先于列方程）**：
   - **代入排除**：选项是具体数、条件多且好验证 → 从中间项或最好算的项代入；
   - **整除**：题干有"整除 / 倍数 / 比例 / 平均 / 每……"→ 答案应能被某数整除（3、9 看各位数字和）；
   - **奇偶 / 尾数**：不定方程、和差关系 → 用奇偶性、尾数（系数尾数为 0、5 时）排除；
   - **赋值**：只给比例、不给具体量 → 赋值（工作总量取时间最小公倍数、效率取最简比）。
3. **定题型**：按下方「题型识别表」判断专题，需要公式时读对应章节。
4. **列式计算**：写出公式 → 代数 → 逐步算。**按考生手算的思路写**：优先整数赋值、凑整、约分；python 只用来核对结果，不能因为有 python 就接受满屏小数的算法。
5. **验算**：把结果代回题干条件逐一检查，必须等于正确答案。

## 核心框架（最常用的秒杀判断）
- **赋值只赋整数，禁止赋 1 / 分数 / 小数**：解析是给考生手算看的。工作总量赋"所有完整时间的最小公倍数"，效率赋最简整数比，溶质赋浓度的最小公倍数。
- **时间藏在"几小时完成几分之几"里 → 先换算成完整时间**：3 小时完成 1/4 → 单独需 12 小时；2 小时完成剩余 3/4 的 1/3（=1/4）→ 单独需 8 小时；再取 12、8 的最小公倍数 24 为总量。
- **问什么设什么**；有比例就设比例中的"1 份"为 x。
- **隔 n 天 = 每 n+1 天**；多个周期找最小公倍数。
- **十字交叉求出的比是"分母之比"**（溶液题就是溶液质量之比）。
- **等距离平均速度 = 2v₁v₂/(v₁+v₂)**，不是算术平均。
- **最不利原则**：先构造最不利的情况，再"+1"。
- **和定最值**：问最大，其他尽量小；问最小，其他尽量大；注意"各不相同"。
- **利润率以成本为基数**；折扣 = 实际售价 / 定价。
- **容斥**：总数 − 都不 = A + B − 两者都。

## 解析写法
每道题按下面结构写，列式要落到题干原文的具体数据和条件（引用"每隔 3 天""至少 1 个"这类原文词），用本 skill 的方法名（赋值、十字交叉、插板、最不利……）。**计算要写完整、可复核**，结果必须等于正确答案；和正确答案对不上时，先查读题和单位，还不对就标 `⚠ 待核对：<哪一步对不上>`，不要硬凑。

```
【答案】X
【题型】行程·相遇追及 / 排列组合·插板 / ……（用本 skill 专题名）
【秒杀检查】代入 / 整除 / 奇偶 / 尾数 / 赋值：能否直接锁定或排除哪些选项（不能就写"无"）
【方法】用的公式或思路（写出公式原式，如"相遇路程 = 速度和 × 相遇时间"）
【赋值】（用了赋值时必写）赋什么为多少、为什么（如"甲 12 小时、乙 8 小时 → 总量赋 24 → 甲效率 2、乙效率 3"）；**不许赋 1**
【计算】① 列式……　② 代数……　③ 得出……
【验算】把结果代回题干：……✓
【易错】我选 Y 错在……（如：隔 n 天当成每 n 天、十字交叉比例取反、漏了"每人至少一个"）；答对时省略
```

## 被 xingce-jiexi-all 调度时

被总调度 skill 派来处理某一季的本板块时，按下面流程**直接把解析写进板块 md 文件**，不在对话里输出长篇解析。

`<jiexi>` 指 `xingce-jiexi-all/scripts/jiexi.py`（和本 skill 在同一个 skills 目录下）。路径一律加英文双引号；命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。

**直接开始，不要摸索**：用户说“给第N季生成解析 / 只做某板块”时，直接运行下面的命令，`<季>` 写季数（如 `36`）即可，脚本会自己找到目录。**不要** ls / find / grep 库里的文件，**不要**读 jiexi.py 源码、board-map.md、`projects/` 等目录，**也不要打开板块 md 文件本身**——题目、答案、截图路径 `next` 都会打印出来，写入用 `write`。

**Windows PowerShell**：中文输出会乱码，每条 python 命令前固定加 `[Console]::OutputEncoding=[Text.Encoding]::UTF8;`（同一行），不用先试一次再加。

1. 取一批题：`python "<jiexi>" next <季> 数量关系 [--mode 错题|全部]`
   输出里有板块文件路径、本批题号、题干、选项、正确答案、我的答案，以及截图完整路径。有 `[截图]` 的必须打开截图看。**看图预算**：原图只读 1 次；看不清时最多再读 2 次局部放大；**不要安装任何软件包**（pip install 等），系统里没有的工具就不用；还是看不清就写 `⚠ 待核对：截图看不清`，接着做下一题。
2. 按上面的「解题步骤 / 题型识别」解这一批题，遵守：
   - **以正确答案为锚**：推导必须落到给出的正确答案；推不出来就写一行 `⚠ 待核对：<卡在哪一步>`，不要硬编；
   - 我答错时，点出我选的选项错在哪；
   - **真用上面的解题方法**：按「解析写法」逐段写，每段落到原文的句子 / 词语，用本 skill 的术语，不要只贴术语名。
3. 把这批解析写进 `next` 打印的临时文件（`<第N季目录>/.jiexi-tmp.md`），每题以 `=== 题号` 开头：
   ```
   === 36
   【答案】B
   【秒杀检查】……
   === 37
   ……
   ```
   然后写入板块 md：`python "<jiexi>" write <季> 数量关系`
   （脚本会给每行加 `> `，只写空的复盘栏，不会覆盖已有笔记。）
4. 重复 1–3，直到 `next` 显示“没有待解析的题”。
5. 检查格式：`python "<jiexi>" check <季> 数量关系`，有 ❌ 就按提示修好。
6. 回报一句话：写入了几题、哪些题标了待核对。
