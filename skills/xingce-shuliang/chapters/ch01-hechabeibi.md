# ch01 和差倍比与不定方程

## 方法（遇到 X → 用）
- **方程法**：题干有明显等量关系与不变量 → 问什么设什么；有比例关系时设比例中的"1 份"为 x。
- **不定方程**：未知数多于方程，但要求正整数（人数、物品数）→
  - 倍数法：A+B=C 中两个数是同一个数的倍数，第三个也是（3x+7y=33 → 7y 是 3 的倍数）；
  - 奇偶性：奇±奇=偶，偶±偶=偶，奇±偶=奇；奇×奇=奇，偶×偶=偶，奇×偶=偶；
  - 尾数法：系数尾数为 0、5 时（14x+5y=124 → 5y 尾数只能为 0 → 14x 尾数为 4）。
- **列表法**：信息分两个维度（人、时间）→ 画表填已知，找等量关系列方程。
- **整除特性**：a、b 能被 c 整除，则 a±b 也能；被 3、9 整除 ↔ 各位数字和能被 3、9 整除；被 2/5、4/25、8/125 整除看末一、二、三位；题中有"整除 / 乘积"字样优先考虑 3、9。
- **倍数特性**：y = (a/b)x（a/b 最简），则 x 是 b 的倍数，y 是 a 的倍数。
- **赋值法**：只有比例、没有具体数值 → 赋值；**赋零法**：求 A+B+C 的和，可设某个未知数为 0，求出另外两个，和不变。
- **比例法**：多个比例关系都和某个中间量相关 → 以不变的中间量把比例统一。

## 典型例题

### 例 1（题型：不定方程·倍数法；自拟示例，已验算）
题干：3x+7y=33，x、y 均为正整数，则 x 为（ ）。A.1 B.2 C.3 D.4
答案：D
解法：3x 和 33 都是 3 的倍数 → 7y 也是 3 的倍数 → y 是 3 的倍数；7y<33 → y=3 → 3x=12 → x=4。验算：3×4+7×3=33 ✓
易错点：直接枚举容易漏解或算错；先用倍数锁定 y 的取值范围。

## 关键要点
1. 不定方程三板斧：倍数、奇偶、尾数。
2. 只有比例 → 赋值或比例法；问和 → 可试赋零。
