# ch04 溶液问题与十字交叉法

## 方法（遇到 X → 用）
- **核心公式**：浓度 = 溶质 ÷ 溶液；溶液 = 溶质 + 溶剂。
- **溶液混合**：溶质质量守恒，各部分溶质之和 = 混合溶液溶质，抓溶质不变列方程。
- **蒸发稀释**：先取浓度的最小公倍数赋值溶质，再还原蒸发 / 稀释过程（对应溶剂减少或增加），抓溶质不变。
- **十字交叉（类浓度）**：溶液 A 浓度 a、溶液 B 浓度 b，混合后浓度 R → (R−b)/(a−R) = A 的质量 / B 的质量。
  - 使用情景：凡是能写成 A=B/C 的比例关系都可当作类浓度（A 当浓度、B 当溶质、C 当溶液）；两部分和混合后的浓度都已知时，求两部分质量之比。
  - **难点：十字交叉求出的比例一定是"分母"之比**。

## 典型例题

### 例 1（题型：十字交叉；自拟示例，已验算）
题干：浓度 20% 的溶液 A 与浓度 50% 的溶液 B 混合成浓度 30% 的溶液，A 与 B 的质量比是（ ）。A.1:2 B.2:1 C.2:3 D.3:2
答案：B
解法：(R−b)/(a−R)=(30−50)/(20−30)=2 → A:B=2:1。验算：(2×20%+1×50%)÷3=30% ✓
易错点：比例取反成 1:2；求出的是分母（溶液质量）之比，不是溶质之比。

## 关键要点
1. 溶液题抓"溶质不变"。
2. 十字交叉：差值交叉相比，得分母之比。
