# ch06 最值问题

## 方法（遇到 X → 用）
- **和定最值**：遵循"问最大，其他尽量小；问最小，其他尽量大"，问什么设什么，注意排名要求，最后用总量列方程。
  - 各部分**不能相等**：按递减 1 构造；各部分**可以相等**：注意题干是否要求各不相同。
- **最不利极限**：先构造最不利的情况，再"加一"就能保证。
- **函数最值**：y = ax² + bx + c，当 x = −b/(2a) 时取最值（a>0 最小，a<0 最大）；y = (x−a)(x−b) 时，x = (a+b)/2 取最值。

## 典型例题

### 例 1（题型：和定最值；自拟示例，已验算）
题干：5 个互不相同的正整数之和为 20，其中最大的数最少是多少？ A.5 B.6 C.7 D.8
答案：B
解法：设最大为 x，其他尽量大：x−1、x−2、x−3、x−4 → 5x−10 ≥ 20 → x ≥ 6；6、5、4、3、2 之和 =20 ✓
易错点：忘了"各不相同"而按平均数 4 作答。

### 例 2（题型：最不利极限；自拟示例，已验算）
题干：袋中红、黄、蓝球各 10 个，至少摸出几个才能保证有 3 个同色？ A.6 B.7 C.8 D.9
答案：B
解法：最不利：每色各摸 2 个 =6 个仍不满足 → 再 +1 → 7 个。验算：7 个分到 3 种颜色，必有一色 ≥3 ✓
易错点：忘了"+1"答 6。

## 关键要点
1. 和定最值：问大则他小，问小则他大。
2. 最不利 = 最坏情况 + 1。
