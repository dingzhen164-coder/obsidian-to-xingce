# ch07 几何问题

## 方法（遇到 X → 用）
- **平面周长**：长方形 2(a+b)；正方形 4a；圆 2πr；弧长 l = n/360°×2πr = nπr/180°。
- **平面面积**：正方形 a²；长方形 ab；三角形 ½ 底×高；梯形 (上底+下底)×高/2；菱形 对角线×对角线/2；正三角形 (√3/4)×边长²；扇形 n/360°×πr² = lr/2。
- **立体表面积**：正方体 6a²；长方体 2(ab+ac+bc)；球 4πr² = πD²；圆柱 2πr²+2πrh；圆锥 πr²+πrl；圆台 π(r²+R²+rl+Rl)，母线 l = √((R−r)²+h²)；棱锥 = 侧面积 + 底面积。
- **立体体积**：正方体 a³；长方体 abc；球 (4/3)πr³；圆柱 πr²h；圆台 (1/3)πh(r²+Rr+R²)；圆锥 (1/3)Sh = (1/3)πr²h；棱锥 (1/3)Sh。
- **直角三角形**：勾股定理 c² = a²+b²；30°-60° 直角三角形 1:√3:2；等腰直角 1:1:√2；常见勾股数 (3,4,5)(6,8,10)(5,12,13)(7,24,25)(8,15,17)(9,40,41)。
- **三角形等底等高**：底一定，面积比 = 高之比；高一定，面积比 = 底之比。
- **立体取巧**：有切割、拼接时结合选项秒杀。
- **等比例放缩**：边长（半径）变为 n 倍 → 周长 n 倍、面积 n² 倍、体积 n³ 倍。
- **几何最值**：周长一定越接近圆面积越大（面积一定越接近圆周长越小）；表面积一定越接近球体积越大；矩形中周长一定正方形面积最大、面积一定正方形周长最小。
- **最短路径**：两点之间线段最短（作对称点连线）；点到直线垂线段最短；两点在不同面上 → 展开成同一平面。

## 典型例题

### 例 1（题型：等比例放缩 / 勾股；自拟示例，已验算）
题干：一个正方体棱长扩大到原来的 2 倍，体积变为原来的几倍？ A.2 B.4 C.6 D.8
答案：D
解法：等比例放缩：边长 n 倍 → 体积 n³ 倍 → 2³=8。验算：a³→(2a)³=8a³ ✓
易错点：按面积 n² 倍答 4。

## 关键要点
1. 公式题先认图形，再选公式。
2. 放缩：周长 n、面积 n²、体积 n³。
