# ch08 排列组合与概率

## 方法（遇到 X → 用）
- **基础**：有序为排列 A(n,m)=n(n−1)…(n−m+1)，无序为组合 C(n,m)=A(n,m)/A(m,m)；分类用加法、分步用乘法；从特殊入手；正面情况复杂时用**全部减不符**。
- **概率**：多个独立事件同时或先后发生 → 概率相乘；多个互斥事件 → 概率相加；P = 符合要求的情况数 / 所有可能的情况数；比赛型（独立重复）注意"几局几胜"里最后一局必须胜；二人同组（跟屁虫模型）→ 先让一人任选，再算另一人与其同组的概率。
- **相邻（捆绑法）**：必须相邻的元素捆在一起看作一个元素；注意总元素个数变了，捆绑内部是否排序。
- **不相邻（插空法）**：先排没有要求的元素，再把不相邻的元素插入空位；注意是否有序。
- **相同元素分配（插板法）**：n 个相同元素分给 m 人、每人至少一个 → n−1 个空里插 m−1 块板 = C(n−1, m−1)。每人至少 x 个（x>1）→ 先给每人 x−1 个；可以分 0 个 → 先向每人借 1 个。
- **错位排列**：n 个元素都不在原位：D1=0、D2=1、D3=2、D4=9、D5=44、D6=265。
- **环形排列**：n 个元素围成一圈 = A(n−1, n−1)。
- **重复排列**：每个元素有 n 种选择，m 个元素共 n^m 种。

## 典型例题

### 例 1（题型：捆绑法；自拟示例，已验算）
题干：5 人排成一排，甲、乙必须相邻，有多少种排法？ A.24 B.48 C.60 D.120
答案：B
解法：把甲乙捆成 1 个元素 → 4 个元素全排 A(4,4)=24 → 甲乙内部 A(2,2)=2 → 24×2=48。
易错点：忘了捆绑内部的排序答 24。

### 例 2（题型：插板法；自拟示例，已验算）
题干：10 个相同的苹果分给 3 个人，每人至少 1 个，有多少种分法？ A.28 B.36 C.45 D.120
答案：B
解法：10 个苹果形成 9 个空，插 2 块板 → C(9,2)=36。
易错点：用 C(10,3) 或当成不同元素分配。

## 关键要点
1. 相邻捆绑、不相邻插空、相同元素插板。
2. 正面复杂就全部减不符。
