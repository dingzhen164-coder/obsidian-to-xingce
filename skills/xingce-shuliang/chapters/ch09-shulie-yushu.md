# ch09 数列问题与余数问题

## 方法（遇到 X → 用）
- **等差数列**：通项 aₙ = a₁+(n−1)d = aₘ+(n−m)d；求和 Sₙ = 项数 × 中位数 = 项数 × 平均数 = n(a₁+aₙ)/2；性质 2aₙ = aₙ₋₁+aₙ₊₁，m+n=p+q 时 aₘ+aₙ = aₚ+a_q。
  - 常用：1+3+5+…+(2n−1) = n²；1~4 之和 10，1~9 之和 45，1~10 之和 55。
- **等比数列**：通项 aₙ = a₁qⁿ⁻¹ = aₘqⁿ⁻ᵐ；求和 q=1 时 Sₙ = na₁，q≠1 时 Sₙ = a₁(1−qⁿ)/(1−q)；性质 aₙ² = aₙ₋₁aₙ₊₁，m+n=p+q 时 aₘaₙ = aₚa_q。
- **斐波那契数列**：1、1、2、3、5、8、13、21、34……从第三项起每项等于前两项之和。
- **余数**：余同取余 → 被除数 = 最小公倍数 × n + 余数；和同加和（除数与余数之和相同）→ 被除数 = 最小公倍数 × n + 和；差同减差（除数与余数之差相同）→ 被除数 = 最小公倍数 × n − 差；无余数特征 → 被除数 = 最小公倍数 × n + x，依次试解。

## 典型例题

### 例 1（题型：余数·余同取余；自拟示例，已验算）
题干：一个大于 1 的整数除以 3、4、5 都余 1，这个数最小是多少？ A.31 B.49 C.61 D.121
答案：C
解法：余同取余：3、4、5 的最小公倍数 60 → 60n+1，n=1 → 61。验算：61÷3 余 1、÷4 余 1、÷5 余 1 ✓
易错点：忽略"大于 1"答 1；或用 3×4×5 恰巧相同但不理解最小公倍数。

### 例 2（题型：等差求和；自拟示例，已验算）
题干：1+3+5+…+19 等于多少？ A.90 B.100 C.110 D.121
答案：B
解法：奇数列和 = n²，共 10 项 → 10²=100。
易错点：项数数错为 9 或 19。

## 关键要点
1. 等差求和 = 项数 × 中位数。
2. 余数：余同取余、和同加和、差同减差。
