# ch10 行程问题

## 方法（遇到 X → 用）
- **基础**：路程 = 速度 × 时间；单位换算 1m/s = 3.6km/h。
  - 比例法：时间相同，路程与速度成正比；速度相同，路程与时间成正比；路程相同，速度与时间成反比。
  - 方程法（套基础公式）、画图法（画图模拟全过程）。
- **直线相遇追及**：相遇路程（路程和）= 速度和 × 相遇时间；追及距离（路程差）= 速度差 × 追及时间。
- **直线多次相遇**：两端出发第 n 次相遇，路程和 = (2n−1)S（S 为两端距离）；同端出发，路程和 = 2nS（S 为起点与折返点距离）。
- **环形**：同起点同向追及，追及距离 = 路程差 = 1 圈（"套圈"）；同起点反向相遇，相遇路程 = 路程和 = 1 圈。
- **流水行船**：v顺 = v船 + v水；v逆 = v船 − v水；v船 = (v顺+v逆)/2；v水 = (v顺−v逆)/2。
- **火车过桥**：完全过桥路程 = L桥 + L车；完全在桥上路程 = L桥 − L车。
- **匀加速**：v平均 = (v初+v末)/2；vₜ = v₀ + at。
- **等距离平均速度**：v平均 = 2v₁v₂/(v₁+v₂)，**两段路程相等才能用**。

## 典型例题

### 例 1（题型：相遇；自拟示例，已验算）
题干：A、B 两地相距 300 千米，甲车速度 60 千米/时，乙车 40 千米/时，同时从两地相向而行，几小时相遇？ A.2 B.3 C.4 D.5
答案：B
解法：相遇时间 = 路程和 ÷ 速度和 =300÷(60+40)=3。验算：60×3+40×3=300 ✓
易错点：用速度差算成追及。

### 例 2（题型：等距离平均速度；自拟示例，已验算）
题干：去程速度 60、回程速度 40（路程相同），全程平均速度是多少？ A.45 B.48 C.50 D.52
答案：B
解法：2×60×40÷(60+40)=48。验算：设单程 120，总时间 2+3=5，总路程 240，240÷5=48 ✓
易错点：用算术平均答 50。

## 关键要点
1. 相遇看速度和，追及看速度差。
2. 多次相遇：两端 (2n−1)S，同端 2nS。
