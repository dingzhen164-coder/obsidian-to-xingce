# ch12 方阵、植树、比赛问题

## 方法（遇到 X → 用）
- **方阵**：总人数 = n²；每层人数 = (每边人数 − 1) × 4 = 每边人数 × 4 − 4；相邻两层人数差 8。
- **植树**：间隔数 n = 路长 ÷ 间隔；两端都植 → n+1 棵；一端植或环形 → n 棵；两端都不植 → n−1 棵；重合棵树 → 求间隔的最小公倍数，再按一般植树问题求重合棵数。
- **比赛**：单循环 n(n−1)/2 场；双循环 n(n−1) 场；淘汰赛决出冠军 n−1 场；淘汰赛轮次：上一轮队数为奇数时有一队轮空，队数接近 2 的 n 次方时共打 n 轮；已赛 / 未赛问题用连线法（已完成比赛数 = 该点发出的射线数）。

## 典型例题

### 例 1（题型：植树；自拟示例，已验算）
题干：一条路长 100 米，每隔 5 米种一棵树，两端都种，共种几棵？ A.19 B.20 C.21 D.22
答案：C
解法：间隔数 =100÷5=20 → 两端都种 20+1=21。
易错点：按一端植树答 20。

### 例 2（题型：单循环赛；自拟示例，已验算）
题干：8 支队伍进行单循环赛，共需比赛多少场？ A.28 B.32 C.56 D.64
答案：A
解法：8×7÷2=28。
易错点：按双循环答 56。

## 关键要点
1. 植树：两端 n+1、一端 / 环形 n、两端都不 n−1。
2. 单循环 n(n−1)/2，淘汰赛 n−1。
