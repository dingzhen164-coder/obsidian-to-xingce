## 二、每类题怎么下手（可照做的动作）
1. **代入排除**：条件多、选项是具体数 → 从最好算的选项代入，满足全部条件即选。
2. **整除**：比例、平均、倍数、"每……" → 答案被某数整除；3、9 看各位和。
3. **奇偶 / 尾数**：不定方程先看奇偶，系数尾数 0 或 5 时看尾数。
4. **赋值**：只有比例 → 工作总量赋时间最小公倍数、效率赋最简比、溶质赋浓度的最小公倍数。
5. **方程**：问什么设什么；比例关系设"1 份"。

## 三、选项陷阱清单
| 陷阱 | 怎么识别 |
| --- | --- |
| 隔 n 天当成每 n 天 | "每隔 n 天" = 周期 n+1 |
| 十字交叉比例取反 | 求出的是**分母**之比；(R−b)/(a−R) = A 的量 / B 的量 |
| 等距离平均速度用算术平均 | 用 2v₁v₂/(v₁+v₂)，且两段路程必须相等 |
| 利润率基数错 | 利润率 = 利润 / **成本** |
| 插板漏"每人至少一个"的构造 | 可分 0 个时先每人借 1 个再插板 |
| 最不利忘了"+1" | 最不利情况数 + 1 才能"保证" |
| 容斥重复部分减错 | 三集合要区分"总人次 − 重复部分" |
| 植树两端情况混淆 | 两端都植 n+1、一端 / 环形 n、两端都不植 n−1 |
| 闰年判断 | 能被 4 整除且不能被 100 整除；整百年须被 400 整除 |
| 捆绑后忘了内部排序 | 捆绑在一起的元素内部是否有序 |
