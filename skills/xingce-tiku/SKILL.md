# 真题入库（试炼塔题库）

> **先用程序自带的导入**：行测修仙传网页「试炼塔 → 📥 导入真题」能一键导入模考复盘和 OCR txt（不花 AI token），拆不干净的题会放进 `训练/题库/_待修/`。
> 这个 skill 用于用户明确要 AI 精修的情况（比如待修文件里的题太多、想让 AI 逐题修好），比较费 token。处理待修文件时，按下面第 3 步的要求修题，改好清空“检查”，再让用户在网页上点「重新导入」。

## 目录约定

Obsidian 库根目录（`行测obsidian/行测/`）：

```
训练/题库/
├── 论证逻辑真题.md … 资料分析真题.md   ← 试炼塔读的题库，一个板块一个文件（程序启动时自动建好模板）
├── 图片/图形推理/、图片/资料分析/       ← 题目配图，题干里用 ![[训练/题库/图片/<板块>/<编号>.png]] 引用
└── _待入库/<名称>.md                    ← 中间稿：脚本拆好的题，核对完再入库
FB模考试卷复盘/板块复盘/第N季/            ← xingce-mokao-split 拆好的模考（有的话优先用它，带截图）
```

试炼塔的 12 个板块：政治理论、常识判断、逻辑填空、片段阅读（中心理解、语句排序都算这里）、数量关系、图形推理、
定义判断、类比推理、论证逻辑、形式逻辑、一拖五、资料分析。

题库里一道题的格式（试炼塔按这个读，**小节标题不能改**）：

```markdown
## 题目 粉笔36季-086
### 知识点
语义关系
### 题干
（粉笔第36季模考）钢笔：墨水
### 选项
A. 汽车：汽油
B. 书：纸
C. 水：冰
D. 灯：光
### 答案
A
### 解析
（待补）
```

- **来源**：写在题干最前面的括号里，如“（粉笔第36季模考）”“（2025年国考）”“（2024年浙江省考）”。没有来源就不写括号。
- **编号**：固定身份，不能改、不能重复。脚本自动生成：模考 `粉笔36季-086`（原题号），练习册 `<书名>-<第几套>-<题号>`。
- **答案**：一个字母；不知道写“（待补）”，这样的题试炼塔先不出。
- **解析**：一律先写“（待补）”，以后用解题 skill 补。

## 工作流程

命令里的 `python`：Windows 用 `python`（不行换 `py`），Mac 用 `python3`。路径含中文和括号，必须加英文双引号。
脚本只用 Python 标准库；输入是 PDF 时才需要 `pip install pymupdf`。

1. **确认输入和来源**：拿到文件的完整路径。来源脚本会从文件开头自动认（“第三十六季模考” → 粉笔第36季模考，“2025年…国家公务员” → 2025年国考）；
   认不出、而用户说了或文件名里有，就用 `--source` 指定；练习册通常没有来源，传 `--source ""`。

2. **拆题，生成中间稿**：
   ```
   python "<本skill目录>/scripts/tiku.py" prepare "<txt或pdf完整路径>" [--source "2025年国考"] [--board 论证逻辑] [--name 名称] [--id-prefix 编号前缀]
   ```
   - 粉笔模考：如果 `FB模考试卷复盘/板块复盘/第N季/` 已经拆过（xingce-mokao-split），脚本会**直接用复盘文件**——题干、选项、答案、截图都准确。
     没拆过就从 txt 拆，但粉笔 OCR 的文字顺序会乱（题干被答案行截断、B/D 选项挪到下一题前面），**每题都要对照原文修**。
     这时最好先建议用户用 xingce-mokao-split 拆一遍 PDF（还能得到图形推理、资料分析的截图），再回来入库。
   - 练习册：给一个短的编号前缀，如 `--id-prefix 四海逻辑600`。整本都是一个板块时加 `--board`。
   - 也可以直接给一季的复盘目录：`prepare "<库>/FB模考试卷复盘/板块复盘/第36季"`。
   - 中间稿已存在会拒绝覆盖（可能上次没提交完）；确认要重拆才加 `--force`。

3. **核对中间稿**（`训练/题库/_待入库/<名称>.md`）。分批做，每批 10–20 题，做完一批立刻保存。每道题：
   - **板块**：确认/改成上面 12 个之一。
   - **知识点**：把“待分类”改成具体知识点（见下表）。优先用 `训练/骨架/<板块>.md` 里的 `##` 大项名（例如资料分析用“基期量”“两期比重差（比重增量）”），
     这样试炼塔的知识点和功法对得上；没有骨架就用对应解题 skill 里的题型分类。
   - **题干、选项**：对照原文（用户给的 txt）修好：去掉页码、广告（“最新一手公考资料…”）、书眉；把被截断的题干接回去；
     A–D 四个选项各占一行。**不要改写题目文字**，只修 OCR 造成的错乱。错别字明显是 OCR 错的（“自已”“丛家雉”）可以照原意改正。
   - **拆开并在一起的题**：检查里写“下一个题号没识别到”时，从选项末尾把下一题剪出来，照格式新建一个 `## 题目` 块，编号按规则补上。
   - **答案**：脚本读到的答案保留；**没有答案就留“（待补）”，绝不自己解题填答案**。
   - **共用材料**（资料分析、一拖五）：同组每道题的题干开头都要有材料（文字或材料截图）。
   - **配图**：图形推理、资料分析没有图就做不了。有模考截图时脚本已经写好 `![[S36-Q077.png]]`，入库时自动复制到 `训练/题库/图片/`；
     没有截图的，在汇报里列出“请把这些图存到 训练/题库/图片/<板块>/<编号>.png”。
   - 都改好后把 `### 检查` 下面清空。实在修不好的题保留检查说明，留在中间稿里。

4. **入库**：
   ```
   python "<本skill目录>/scripts/tiku.py" commit "<中间稿完整路径>" [--dry-run]
   ```
   就绪的题（板块、知识点已填，检查已清空，四个选项齐全）追加到对应 `<板块>真题.md` 末尾，来源自动加到题干前；
   编号相同或题干相同的题跳过（不会重复入库）；没就绪的题留在中间稿，下次接着核对再 commit。全部入库后中间稿自动删除。

5. **汇报**：各板块入库多少题、跳过的重复题、还留在中间稿的题和原因、缺哪些图、多少题答案待补。

## 补答案

练习册的答案常在另一本（或书后答案页）。拿到答案表后：
```
python "<本skill目录>/scripts/tiku.py" answers "<题库或中间稿.md>" "<答案文本或答案文件>" --prefix 四海逻辑600-03
```
`--prefix` 是“编号去掉最后的题号”（上例补第 3 套）。答案表支持“1-5 ABCDA”“1.A 2.B”或一串连续的 ABCD。
先用 `--dry-run` 看补了几题，对得上再正式运行。

## 重要约束

- **只追加，不改已有题目**：题库里已有的题（尤其编号）一律不动；试炼塔用编号记录作答历史。
- 不编造答案、不写解析（解析一律“（待补）”，以后用别的 skill 补）。
- 不润色题目文字，只修 OCR 错乱。
- 文件统一 UTF-8 + LF（脚本已处理；手动新建文件时也要注意），Windows / Mac 通过坚果云同步。
- 只写 `训练/题库/` 下的文件；模考复盘目录只读。
